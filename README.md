# Weldon Spring: The Secret Is Out

An educational website about the Weldon Spring disposal site and the St. Louis region's atomic legacy.

## View it locally
Double-click `index.html`, or run:

    python3 -m http.server 8000

Then open http://localhost:8000

## Files
- `index.html` – all page content
- `style.css` – design
- `script.js` – menu, flip cards, map legend, scroll effects
- `images/` – put new photos here (the hero photo can go in as `images/hero.jpg`)
